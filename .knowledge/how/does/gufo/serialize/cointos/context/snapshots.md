`patches/gufo/control.cpp` owns the native file envelope: model/ABI identity, exact tokens and sampler/RNG state, opaque runner payload, and SHA-256 footer. Save captures an immutable native GPU snapshot, serializes into an anonymous mapped file, computes the digest, syncs and publishes. Restore checks the digest/header before importing native state and reattaching continuation. Logical cache admission/retirement belongs to the snapshot-storage owner.
