For new agent-task terminal transitions, the job stores `result_notification_recipients` in the same durable write as its terminal state. The executor service optionally loads `%h/.config/agent-ecosystem/telegram.env`; `outbox.result_recipients()` parses its comma-separated `AGENT_TELEGRAM_ALLOWED_USER_IDS` as integers before terminal publication. A missing variable yields an empty recipient snapshot. Source now skips non-integer entries, retains distinct valid recipients in order, and audits the invalid-entry count; a malformed entry no longer blocks terminal publication. The installed outbox copy matches source after a no-restart deployment; running service behavior remains unqualified. `executor.queue_notifications` and the periodic `watchdog.reconcile_result_notifications` both call `outbox.enqueue_result(user_id, job_id)`. That operation holds `state/outbox-enqueue.lock`, searches all result-message records for the exact `(result_of, user_id)` pair, and creates a new dependent outbox record only when none exists. An existing `delivered`, `delivery_unknown`, `failed`, waiting, or queued record is still the unique record: repair never guesses a send outcome or automatically resends an ambiguous delivery. The watchdog only repairs terminal agent-task records carrying the explicit recipient snapshot, so it does not bulk-notify legacy tasks. Verifier completion snapshots the target's recipients before persisting its terminal result; it does not separately notify for the verifier job.

The notification intent and the outbox file are not one filesystem transaction. The safety property is recoverability plus idempotent reconciliation: a crash after terminal state publication can leave the outbox absent temporarily, and the next watchdog pass creates it once. Outbox delivery itself still has the unavoidable external-send ambiguity handled by `delivery_unknown`. Existing focused temporary-root tests in `tests/test_outbox.py` cover delivered/unknown deduplication, repeated reconciliation, and simulated interruption immediately after terminal publication. A bounded direct check exercised malformed-recipient tolerance and audit without retaining a new regression test under the global MVP policy; source and installed outbox copies match; live end-to-end qualification remains pending; it does not authorize resending historical failed or unknown notifications.
