The workstation's unified RAM is one pool. `memory.py` derives physical headroom from `MemAvailable`, the workstation reserve and any inference-slice allowance. Gufo is charged through host memory, without a separate server allowance. The guard uses physical headroom and PSI; swap occupancy alone is diagnostic. Sustained distress or negative headroom after cache shedding stops background agents uncharged. Unloading requires headroom still negative; recovery waits for configured calm time.

`capacity.py` owns unspent admission capacity. Each active run holds its full configured process cap, converting systemd's binary G units to decimal GB, plus the runner's state-and-scratch claim until native initialization. The full process cap is deliberately conservative even after its process starts consuming RAM. Spawning, native allocation and disposable caches use this same budget. Native initialization spends its own state claim while preserving other claims. Native readiness requires a positive state estimate; unknown capacity refuses new admission. Pending saves and copy-backs remain reserved through fresh measurements. Physical protection and admission capacity are separate signals.

One exception: `capacity.conversation_cache_gb` releases process-cap claims for a Coin conversation's saves and resident state, because a waiting user pays for each refusal in rereads or a failed turn, and the guard sheds caches first. Other claims and the reserve still apply. why/does/coin/reread/its/whole/context/on/every/model/request.md owns the cause. `snapshot refused` events record refused saves.

Native persistence also captures device state before writing its RAM file. Admission covers both the estimated file and a full native state claim for the temporary capture. An unmeasured native file uses the runner's state estimate rather than zero. RAM cache capacity still bounds retained files. Retired files remain charged until physical deletion; release credit is capped by measured headroom less outstanding saves/unspills. Independent RAM/disk cleanup keeps filesystem deletion outside the state lock.

Native task state belongs to a running client or in-flight thought, rather than a task's longer conversation lifetime. Independent cleanup retires GPU states for tasks awaiting review or waiting without a run. Live clients keep state between tool calls; transcripts, sessions, work, budgets and persistence hints survive retirement. Ordinary hot switches retain pointer selection and never serialize live resident state.
