A live run closes only after its exact bound worker process has ended, proxy requests are no longer in flight, and the proxy has persisted verified backend-end evidence. `ecosystem/inference_proxy.py` supplies `completed_run_termination` and `revoke_proxy_credential`; `ecosystem/inference_capacity.py` accepts a release only for the expected binding, observer, clock domain and fresh evidence. `executor.close_runner_round` reaps the process group, releases the proxy/inference sequence, then releases/observes the worker lease. An HTTP disconnect or successful tool exit alone does not prove GPU occupancy ended.

The proxy records a claim at admission and preserves slot evidence for exact-incarnation termination. Post-admission preflight failure now finishes that claim without asserting backend termination; a forwarding failure does likewise. See `how/does/the/inference/proxy/clean/up/an/admitted/claim/when/preflight/or/forwarding/fails.md` for the HTTP boundary. Dead-owner reconciliation can finish abandoned claims from that evidence, including a uniquely correlated idle slot while another slot remains busy. A bounded terminal non-streaming JSON response plus fresh free-slot observation can close a rapid request whose start flip was missed; malformed, truncated or nonterminal responses do not qualify. A used history-unknown credential without verified backend end remains allocated. Live mixed-slot qualification previously reclaimed a dead ghost while another slot was busy; streaming and live-owner idle reservations need separate qualification.

There is also a bookkeeping-only closure path for an inference lease R3 already released. `reconcile_released_proxy_credentials` acquires the workload/capacity/proxy locks and revokes a `closing` or `releasing` credential only when it has no in-flight claim, its exact bound process is ended, and the capacity lease contains a matching accepted release binding, observer and evidence ID. It stores that prior released sequence; it does not create fresh termination evidence or release capacity again. `reconcile_available_capacity` calls this before normal dead-owner reconciliation. Twelve legacy matches in the installed runtime were closed through this path; the exact historical interruption point is unknown. See `why/do/some/inference/proxy/credentials/remain/closing/after/their/capacity/leases/are/released.md` for the focused proof and runtime snapshot.
