Task instructions generated by Python in `ecosystem/` and handed to an agent use
portable shell-facing paths or runtime-root interpolation, never a fixed
`/home/david/...` absolute path, for the same reason as role prompts: the agent
may run under a different checkout or home layout.

Currently guarded strings:

- `ecosystem/watchdog.py` steward-review task interpolates cli.ROOT for the workspace and cli.ROOT/state/conversations for operational records. The installed runtime must not read the retired checkout state directory.
- `ecosystem/resource_control.py` survivor incident task:
  "`~/Projects/CointOS/scripts/resource-control recover`".

`tests/test_agent_task_path_portability.py` is the regression guard: it fails if
any `/home/david/` path reappears in either file and checks the portable
current portable expressions stay. The old watchdog literal assertion failed after correcting runtime paths; its existing expected strings were updated, with no new test cases. The role-prompt half of the same convention is recorded in
[`../role_prompts/use_home_specifiers.md`](../role_prompts/use_home_specifiers.md).
