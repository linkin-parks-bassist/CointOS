CointOS runs from this checkout on `rebuild/simple-core`. The implementation includes the pre-emptive rebuild, subsequent improvements and verified uncharged halt recovery. The earlier request-scheduling core is archived, not the active runtime.

**Implementation.** `backend_llama.py` owns Lemonade/llama-server; `scheduler.py` owns pure policy; `lanes.py` owns stepped thoughts, switches and snapshot tiers; `gateway.py` owns the gateway, API and live stream; `work.py` owns tasks and agent supervision; `agents.py` owns independent systemd agent runs; `memory.py`, `checks.py`, `daemon.py` and `state.py` own measurement, checks and the ledger. Supporting modules provide queues, CLI, Coin, kt MCP and viewers. The dashboard is `web/dashboard.html`. The implementation remains around the 3,000-line core budget. All 42 unit tests pass (`python3 -m unittest discover -v`), including durable uncharged halt settlement at the final allowed attempt, retained session/snapshots, repeat-request idempotence, preserved pause, blocked admission and serialized concurrent ledger writes.

**Halt recovery verified live.** Halt goes through the daemon's uncharged settlement path and persists the result before unit teardown. An idle halt/up and an interrupted `add-gcd-lcm` run both stopped the services and unloaded all models. The interrupted task persisted as waiting with runs refunded from 1 to 0 and its session/worktree retained. After up, a different worker resumed that same session/worktree with runs back at 1, both models loaded and all seven checks green; the resumed worker subsequently completed and merged its task. An ordinary daemon restart also adopted the original agent without replacing it. This establishes the single-task recovery path, not the full soak.

**Installed.** Both enabled services run this checkout; `~/.local/bin/cointos` resolves to `bin/cointos`. Old `agent-*` units are inactive; their activatable units are disabled. Snapshots live at `/dev/shm/cointos-contexts` (mode 0777 for Lemonade) and `~/.cache/cointos/contexts`. Only `~/Projects/cointos-sandbox` is configured, by David's choice until acceptance passes. `kill -USR1` on the daemon dumps thread stacks to its journal.

**Design lessons.** Cold reads must finish before equal-class rotation; backend requests must end at bounded steps; snapshot memory counts against Lemonade's cgroup allowance. Checkpoints and suspended snapshots have distinct lifetimes, and eligible snapshots can spill to disk rather than accumulate without bound.
