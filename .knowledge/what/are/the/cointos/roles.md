schema.KINDS fixes role facts; commands become managers. Roles share coordination tools (what/are/the/cointos/agent/capability/gaps.md). Work-shape/completion owners explain stages and receipts. The daemon owns ledger/acceptance. Reports lead with product goals.

**Project trees describe the product only.** Maintain product spec, design, contracts, code facts, defects and remaining steps as if no agents built it. CointOS tasks, roles, construction stages, gates, receipts, packets, audits and retries belong in this tree and diagnostics. roles/_base.md owns this rule.

- **Coin** operates the workstation through filesystem tools and Bash commands via run_command. It reports and controls through Telegram, manages projects/holds/revisions and requests scouts/Operators. Durable deadline/task/service/process wakes survive reboot, run at background priority and recheck replay state. Work explanations and requested-work completion updates use Coin priority without canned notices. Sizeable requested work gets verified completion and milestone messages. Each model round supplies current time; observations/messages retain timestamps.
- **Managers** define coherent behavior boundaries, atomically dispatch children and complete with handoff. Typed queue/revise/check_work validate prerequisites/APIs. Planning merges permit knowledge history only; product changes need review. Implementation/integration revisions retain accepted tests; build repair preserves acceptance. Typed handoffs refuse dead continuations; prose claims do not establish runnable children or their roles. Valid children defer recovery; failed planning reaches its single First Responder. Read-only status belongs to planning/Operators.
- **The steward** is one low-reasoning roaming assignment. It spawns every spawner.steward_every_seconds times one plus active/queued concerns, excluding user-killed tasks; also once after lanes have been free for spawner.idle_steward_seconds and project work settled since the last steward, or on request. It reads whole remaining plans and follows evidence to one useful result. Gardening stale/non-green knowledge and removing completed steps is normal. Approved unowned work is stalled even with green checks/empty queues. It can dispatch and steer work directly or queue a checked manager command. Genuine user-decision receipts enqueue durable explanations; ordinary choices take the recommended engineering path. Questions give context and consequences for a technical user unfamiliar with this code. Coin correlates answers, checks current work and verifies scoped actions. A clean result requires checking the remaining frontier.
- **Test auditors** are medium-reasoning retrospective reviewers: sample accepted work, compare tests with spec, run bounded suites and probe wrong implementations. A concrete gap becomes at most one manager command. They never edit product code/tests/plans/trees; a clean audit is valid.
- **Operators** are managed user sessions, sharing their scheduling class and weight immediately below Coin, regardless of purpose or dispatcher. They own ad-hoc assignments through cointos_dispatch. Direct user/Coin requests get memory-checked priority admission; agent helpers retain ordinary admission. Calling one does not charge the caller. New project Operators inherit construction's write boundary around their own prepared files and allowed tool/knowledge/scratch state with private version-control metadata, preserving other tasks' artifacts. They merge only permitted knowledge/configured non-code; product/protected tests require worker review. Explicit system Operators retain infrastructure scope and do not edit managed products. Existing processes keep launch policy. Explicit user holds prevail. Model-independent observation can queue evidence; substantive Coin notification requires inference. Remote native startup repair remains separate; its handback is not a task receipt.
- **First Responders** minimally investigate to choose the right role and arrange a checked handoff; they own automatic recovery (how/does/cointos/recover/blocked/assignments.md), and **Supervisors** watch over long-running agents (how/does/cointos/supervise/running/agents.md).
- **Workers** own one skeleton/test-contract/implementation/integration item on an isolated branch. Completion requires a changed artifact against the pinned baseline; empty/reverted/report-only work is refused before review. Stage ownership is judged on the branch's net result against main, not its history. Real authored changes already on main remain eligible for incorporation. Every completed test packet receives independent review before satisfying dependencies. Implementers run the hidden packet first, by calling finish rather than writing probes; the first product-test failure reveals failing tests and helpers, then blocks into independent First Responder diagnosis. Revision preserves the branch. Integrators maintain product trees/plans.
- **Integrators** review code/tests against main/contract, maintain product facts and accept through the exact-candidate gate. Test review checks representable witnesses, reachable rejection cases and coherent assertions. Success tests demand promised outputs; errors distinguish phase/provenance. Executed red packets are accepted hidden; green packets publish. Invalid execution/timeouts cannot authorize acceptance. Judgment distinguishes expected assertions from infrastructure failure. Verified landing/incorporation/return is the receipt; blocked work reaches its single First Responder.
- **Gardeners** maintain small verified batches across enabled trees. **Tree auditors** inspect one structural concern across representative leaves. They are bounded, mutually excluded per tree and finish with merged knowledge/receipts.

Config supplies low default reasoning, medium for test writers/managers/integrators; overrides win. Tasks pin recovery defaults/role_budgets and explicit overrides. Managers and Operators use the common configured allowance. Construction and Operators have zero fresh retries. Budgets remain pinned; integrations use their own defaults. Priority: Coin, Operators, Supervisors, First Responders, others.
