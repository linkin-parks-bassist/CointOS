# Lead Agent Integration

## Purpose

The Lead agent serves as a quality gate in the agent ecosystem workflow, ensuring that work is properly completed and handed off before tasks are marked as finished.

## Workflow Integration

1. Worker completes a task
2. Worker provides handoff documentation
3. Lead agent reviews the completed work
4. Lead agent validates that all requirements are met
5. Lead agent either approves completion or requests revisions
6. If approved, the task is marked as complete
7. If rejected, the worker receives feedback and must rework

## Key Responsibilities

- Reviewing task completion against defined criteria
- Validating that all required handoffs have occurred
- Ensuring proper documentation and evidence are provided
- Approving or rejecting task completion
- Requesting additional work when requirements are not met

## Handoff Requirements

The Lead agent enforces these handoff requirements:
- Complete documentation of work performed
- Evidence of testing or validation
- Proper formatting and organization of deliverables
- Clear handoff notes and next steps
