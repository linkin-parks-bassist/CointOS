# Lead Agent Workflow

## Overview

The Lead agent workflow is designed to ensure proper task completion and handoff in the agent ecosystem. It acts as a quality gate between worker completion and final task approval.

## Workflow Steps

1. **Task Receipt**: The Lead agent receives a completed task from a Worker agent
2. **Review Process**: The Lead agent reviews the work against completion criteria
3. **Validation**: The Lead agent verifies that all required handoffs have been performed
4. **Approval/Rejection**: The Lead agent either approves the task completion or requests revisions
5. **Handoff**: If approved, the task is marked as complete and proper handoff occurs

## Review Criteria

The Lead agent checks for:
- Complete documentation of work performed
- Evidence of testing or validation as appropriate
- Proper formatting and organization of deliverables
- Clear handoff notes and next steps
- Compliance with project standards and requirements

## Handoff Requirements

The Lead agent ensures these requirements are met:
- All deliverables are properly documented
- Test evidence is provided when required
- Code quality standards are maintained
- Project conventions are followed
- Any dependencies are properly handled

## Decision Process

When reviewing work, the Lead agent makes decisions based on:
- Whether all requirements have been met
- Quality of documentation and handoff notes
- Completeness of testing or validation
- Adherence to project standards
- Proper organization of deliverables

## Approval Process

Approval is granted only when:
- All review criteria are satisfied
- Proper handoff documentation is provided
- Quality standards are met
- No outstanding issues remain

Rejection occurs when:
- Requirements are not met
- Documentation is incomplete
- Quality standards are not satisfied
- Handoff requirements are not fulfilled
