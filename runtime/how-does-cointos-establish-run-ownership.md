**Run ownership.** Admission reserves a fresh run directory and uses the ledger lock to prevent launch before key persistence and ownership registration. Failed thread/key admission preserves waiting work. Authority reads require regular, non-symlink JSON files and reject duplicate fields; only absence initializes defaults. Damaged ledger, enrollment or key files refuse startup without overwriting ownership. Keys resample collisions; adoption preserves one owner and permits exact retries. Restart adopts exact task or current receipt ownership, preserves sessions and requeues displaced tasks.

The launcher registers an existing construction checkout's knowledge tree before entering its write boundary. Authors can then create answers in their assigned tree while global knowledge access policy remains protected. Registration preserves existing policy and grants no access to other projects.
