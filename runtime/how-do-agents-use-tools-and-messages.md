**Agent tools and messages.** Agents call these controls as role-limited MCP tools named `cointos_<command>`; arguments are plain text, so briefs need no quoting. `cointos_peers` shows other live runs, their purpose, activity and changed files; `cointos_send` messages an active task (`PROJECT:NAME`), `user` (a durable question/message for Telegram delivery; acceptance is not proof of reading), or `mailbox:NAME` (a local external inbox without alerts). External clients read with `cointos inbox --mailbox NAME` and send as themselves with `cointos message --mailbox NAME TO TEXT`; agents cannot use external mailbox identities. `cointos_inbox` reads the agent's unread messages, which tool results announce. Messages coordinate; work moves only through the queue.

Use declared tool fields only. Unsupported arguments refuse rather than silently changing the scope of a check. cointos_check_work checks the caller or a declared proposal and reports binding tests; it has no arbitrary task-target field. cointos_task shows the canonical queue brief and full checked receipt once, with binding tests and typed correction owners. history=true retrieves complete execution metadata, including the original execution briefs and duplicate report fields.
