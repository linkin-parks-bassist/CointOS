**Caches and memory.** The daemon removes unreachable snapshots and abandoned files, retaining history and branches. Longer shared starts preserve shorter reusable tiers. Coin has opaque per-user cache owners; pruning one history preserves other users and the shared system start. Snapshots give way first under memory shortage. Sustained PSI stops background agents uncharged; model unloading requires headroom still negative after shedding. Recovery waits for calm.
