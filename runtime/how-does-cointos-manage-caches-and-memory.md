**Caches and memory.** The daemon removes unreachable snapshots and abandoned files, retaining history and branches. Longer shared starts preserve shorter reusable tiers. Coin has opaque per-user cache owners; pruning one history preserves other users and the shared system start. Admission protects each active agent's full process cap and not-yet-initialized native state; snapshots cannot spend that capacity. Native checkpoint admission covers the RAM file and its temporary GPU capture; an unmeasured file uses the native state estimate. Pending saves and copy-backs remain reserved across memory measurements. Snapshots give way first under memory shortage. Sustained PSI stops background agents uncharged; model unloading requires headroom still negative after shedding. Recovery waits for calm.

Gufo ordinary agent switches atomically select resident per-agent inference state at completed step boundaries. Tensors, sampler/RNG and continuation state stay in place; checkpoint save/restore is separate from hot switching. First admission or changed token histories can initialize from compatible persistence hints. New resident allocation respects host headroom and waits for actual cache reclamation. Native state belongs to a running client: cleanup releases task states with neither a run nor an in-flight thought, including review and waiting tasks. Histories and checkpoint hints retain their longer conversation lifetime. Tool calls do not end a run's residency. Shutdown persists live resident histories. Resident switch events report mode=resident and zero save/transfer/restore durations.
