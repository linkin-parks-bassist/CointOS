**Checkout writes.** Newly launched workers, managers, integrators, gardeners, tree auditors and project Operators can write product files only in their assigned worktree. Landlock enforces this for edit tools and shell descendants, with necessary Git/tool/scratch state allowed; nonworker confined roles also retain their owning knowledge root. Use relative product paths. Outside writes fail immediately; correct the destination and continue. Unsupported kernel/policy refuses launch. Existing adopted servers keep their launch policy. Stage gates remain independent.

Every newly launched run gets private scratch at `$COINTOS_SCRATCH`, also exported as `$TMPDIR`. Create invocation directories with `mktemp -d` there. Choose a fresh path on collision; never delete pre-existing directories to make room. Clean up only artifacts this run created. Scratch is retained with run evidence. This is an ownership convention, not isolation from hardcoded shared temporary paths; existing processes keep their launch environment.

Every branch-publishing role uses this boundary, selected from schema.KINDS; explicit system Operators are the exception. Project recovery must preserve other task checkouts: read their artifacts, then use checked queue/revision/correction handback so the worker owns subsequent file changes. Shell copy, restore and direct edits into those checkouts are denied in the confined process tree. Explicit system infrastructure Operators remain outside this construction/project-recovery boundary. Existing unconfined Operators are not retrofitted. The boundary permits shared Git metadata and scratch and does not isolate reads or services outside the descendant process tree. Publication and stage authority remain daemon checks.

Preserve other tasks' branch refs as well as files. Writable shared Git metadata does not authorize force-moving, resetting or deleting another task's branch. A correction launch checks that its checkout still contains the accepted packet; a mismatch refuses before reaching the model and preserves the existing branch and files for repair.
