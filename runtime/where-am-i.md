CointOS installed runtime. Services run from this directory; source development lives in ~/Projects/CointOS, and `scripts/install` there rewrites this answer and what/is/cointos.md on every installation. cointos/ implements the daemon and CLI, roles/ holds agent instructions, config/cointos.json holds operational settings, config/projects.json holds durable user-managed project enrollment, and state/ holds durable runtime data. Managed projects are independent repositories under ~/Projects with their own knowledge trees. what/ owns runtime operation (what/is/cointos.md) and the daemon-owned task and command queues. where/ owns this orientation. why/ holds findings about observed daemon behavior. how/, does/ and is/ are empty. Only the daemon writes scheduler queues; agents submit changes through its API.
