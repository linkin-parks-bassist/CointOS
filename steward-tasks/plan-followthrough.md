# Find unfinished intentions

Inspect recent run logs and conversations for agents saying they will create,
inspect, test, queue, fix, or continue something. Verify whether the stated next
action actually occurred. Plans and confident summaries are not outcomes. Reconcile
false completion state, queue a bounded continuation when already authorized, or
surface a genuine decision only when David is required. Deduplicate by root task
and never create an unbounded repair loop.
